# Assistants and answer engines.
#
# Be clear about what this section does and does not do. "User-agent: *" above
# already allows every one of these — none of the groups below grant access
# that wasn't there. They are here to state the intent explicitly, so that
# "was Tadapop meant to be readable by assistants?" has a written answer in the
# repo rather than being inferred from a wildcard.
#
# Two of them are load-bearing rather than decorative. Google-Extended and
# Applebot-Extended are opt-OUT-only tokens: they control whether Google and
# Apple may use already-crawled pages for AI answers, and the only way to
# signal "yes" is to not disallow them. Naming them makes that a decision
# somebody made rather than an omission.
#
# One real caveat: a crawler that finds its own name here obeys ONLY its own
# group and ignores "User-agent: *" entirely. So every group below has to be
# complete on its own — if a Disallow is ever added to the wildcard, it must be
# added to each of these too, or these crawlers will keep fetching the path.
#
# The product summary written for exactly these readers is /llms.txt.
# ---------------------------------------------------------------------------
